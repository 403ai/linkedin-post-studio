# Security Policy

## Supported Versions

The `main` branch is the only supported version while the project is early.

## Reporting a Vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If that is unavailable, contact the maintainers through the support path in [SUPPORT.md](SUPPORT.md) and include:

- A short description of the issue.
- Steps to reproduce it.
- The impact you believe it has.
- Any relevant environment details.

## Sensitive Data

Do not include API keys, provider tokens, private LinkedIn drafts, or personal data in issues, pull requests, screenshots, or logs.

AI provider keys should stay in local browser settings or deployment secrets. They should never be committed to the repository.
